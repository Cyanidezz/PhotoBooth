Google Drive ยังไม่เชื่อมต่อ

เลือกกล้อง

ต่อ DSLR → HDMI → Capture Card → USB-C ของ iPad แล้วเปิด Live View บนกล้อง

เลือกชื่อ Capture Card เช่น USB Video หรือ HDMI Capture หากไม่พบ ให้ตรวจว่าอุปกรณ์รองรับ UVC แล้วกดค้นหาอีกครั้ง

ภาพที่ถ่ายเป็นภาพจากวิดีโอ HDMI กรุณาปิดข้อมูลและกรอบโฟกัสบน HDMI ของกล้อง

เชื่อม Google Drive

ส่งภาพที่ใส่เฟรมแล้วไปยังโฟลเดอร์ที่กำหนด หลังถ่ายครบชุด

เปิดโฟลเดอร์ปลายทาง

ตั้งค่าครั้งแรกด้วย Google Cloud ของผู้จัดงาน จากนั้นลงชื่อเข้าใช้และเลือกโฟลเดอร์ปลายทางเพื่ออนุญาตแอป

เปิด Drive API และ Picker API แล้วเพิ่มโดเมนแอปนี้ใน Authorized JavaScript origins และข้อจำกัดเว็บไซต์ของ API key

เมื่อสิทธิ์หมดอายุ ให้เชื่อมใหม่เพื่อส่งรูปที่ค้าง
